## 과거 사례로부터의 학습?

표준화 -> 같은 문제를 반복적으로 풀지 않기 위해서 하는 것.
한 번 푼 문제를 캐싱해두고 다시 풀지 않는 것. 한 번 연산 한 것은 재연산하지 않는 것.
-> 토큰 관점에서는 동일한 문제에 토큰을 다시 태우지 않는 것.
-> 물론 시간과 에너지 절약은 덤.

그렇다면, Agent 개발에 있어서 반복적으로 등장하는 문제가 무엇이냐?

이것을 이해하려면, 전통적인 소프트웨어 개발에서 사람들이 반복해서 풀지 않고자 했던 문제들은 어떤 것들이 있고, 어떻게 그 문제를 한 번 푼걸 재활용했는지, 어디까지 표준화의 영역으로 가져갈지는 어떻게 정했는지? 같은 과거의 사례를 기반으로, 

- 어떤 문제를 반복적으로 풀어야 하며
- 그 문제들을 어떻게 재활용의 영역으로 가져올지

생각을 해보자.
